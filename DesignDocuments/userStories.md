# User Stories

## MVP User Stories

### User Authentication & Account Management

#### Sign Up *
As a new user, I want to create an account so that I can manage my profile and access account features.

#### Sign In *
As a registered user, I want to log in so that I can access my account.

#### Password Reset *
As a registered user, I want to reset my password if I forget it.

### Music Lesson Discovery & Filtering

#### Search by Instrument *
As a visitor, I want to search for lessons by instrument so that I can find teachers offering the lessons I am interested in.

#### Search by Location *
As a visitor, I want to search by ZIP code so that I can find music teachers near me.

#### Filter by Distance *
As a visitor, I want to select a search radius so that I can find teachers within a certain distance of my location.

#### Sort Search Results *
As a visitor, I want to sort lessons by distance or price so that I can find options that meet my needs.

### Teacher & Lesson Information

#### View Teacher Profile *
As a visitor, I want to view a teacher's profile so that I can learn about their experience and the instruments they teach.

#### View Lesson Details *
As a visitor, I want to view lesson descriptions, prices, and durations so that I can decide which lessons interest me.

### Teacher Profile & Lesson Management

#### Create Teacher Profile *
As a registered user, I want to create a teacher profile so that I can advertise my music lessons.

#### Edit Teacher Profile *
As a teacher, I want to update my profile so that my information stays accurate.

#### Add Lesson *
As a teacher, I want to create lesson listings so that students can find the lessons I offer.

#### Edit Lesson *
As a teacher, I want to edit my lesson listings so that I can update pricing, descriptions, and other details.

#### Delete Lesson *
As a teacher, I want to delete my lesson listings so that I can remove lessons I no longer offer.

## NON-MVP User Stories

### Student Features

#### Save Favorite Teachers
As a registered user, I want to save teachers to a favorites list so that I can easily find them later.

#### Contact Teacher
As a student, I want to contact a teacher so that I can ask questions about their lessons.

### Admin & Data Management

#### Admin Edit Lesson
As an admin, I want to edit any lesson listing so that I can correct inaccurate or inappropriate information.

#### Admin Delete Lesson
As an admin, I want to delete inappropriate or outdated lesson listings so that the site maintains accurate information.

#### Admin Manage Teacher Profiles
As an admin, I want to manage teacher profiles so that I can remove inappropriate or misleading information.
